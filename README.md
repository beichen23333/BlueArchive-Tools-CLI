# BlueArchiveTools.CLI - 开发致谢

欢迎使用 **BlueArchiveTools.CLI**！本项目致力于为蔚蓝档案 (Blue Archive) 提供高效、便捷的汉化辅助工具。

为了实现强大的功能，本项目深度集成并借鉴了多个优秀的开源项目。我们向这些项目的开发者表示诚挚的感谢，正是因为他们的贡献，才使得本项目得以顺利实现。

---

## 核心引用

本工具的功能实现离不开以下开源项目的支持：

| 项目名称 | 主要功能描述 | 仓库链接 |
| :--- | :--- | :--- |
| **UABEA** | 强大的 Unity Asset Bundle 处理库，用于解包与打包资产文件。 | [H9per/UABEA](https://github.com/H9per/UABEA) |
| **Il2CppInspectorRedux** | 专业的 Il2Cpp 二进制文件分析工具，用于提取元数据。 | [LukeFZ/Il2CppInspectorRedux](https://github.com/LukeFZ/Il2CppInspectorRedux) |
| **Blue-Archive-Asset-Downloader** | 专门针对蔚蓝档案设计的资源下载器，提供高效的素材获取。 | [ZM-Kimu/Blue-Archive-Asset-Downloader](https://github.com/ZM-Kimu/Blue-Archive-Asset-Downloader) |
| **Cpp2IL** | 顶尖的 C++ 二进制到 C# 代码反编译器。 | [SamboyCoding/Cpp2IL](https://github.com/SamboyCoding/Cpp2IL) |

---

### 开源精神
本项目同样遵循开源精神，所有的引用均严格遵守相应的开源协议。希望这些工具的整合能为蔚蓝档案社区的汉化工作提供有力支持。

如果您在本项目中发现了错误或有改进建议，欢迎随时提交 Issue 或 Pull Request！

> **致敬：** 感谢所有为以上开源项目贡献代码的开发者们。
